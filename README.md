### I'm Jerod

My interests include combinatorics, information theory, and linguistics, and
I enjoy transmuting the things I find most interesting.

**Selected Repos:**

- **[Rampart Chess](https://github.com/jerodmichel/rampart_chess)** — a chess-like strategy game with its own card-casting system, playable online or against a computer. Full web app, Android app, and rules engine.
- **[Mars Symplecticum](https://github.com/jerodmichel/mars_symplecticum)** — a collection of game engines, combinatorial games, and strategy implementations in Bash and Common Lisp, written as the companion software for the book by the same name.
- **[acoustic_modem](https://github.com/jerodmichel/acoustic_modem)** — an acoustic modem for data exfiltration, exploring how far you can push sound as a covert data channel.
- **[apecrank-astro](https://github.com/jerodmichel/apecrank-astro)** — the source for the site [apecrank.net](https://apecrank.net)
